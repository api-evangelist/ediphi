# Ediphi

> Ediphi is a cloud-native preconstruction platform for commercial construction contractors that unifies estimating, cost modeling, GCs & GRs tracking, bid-package contracting, and a shared cloud unit-price catalog in one real-time collaborative workspace. Its "Last Mile" module provides API-driven automation for Excel integration and reporting. Ediphi runs a private application API at api.ediphi.com; there is no public developer portal or published API specification at this time.
